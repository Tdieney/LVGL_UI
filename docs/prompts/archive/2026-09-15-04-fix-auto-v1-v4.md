## 7. Auto/data contract must remain unchanged

| Rule | Default ON/OFF | Editor bounds | Step | Inclusive gap |
|---|---|---|---|---|
| Fan / CO2 ppm | >=1000 / <=800 | 0..10000 | 50 | ON >= OFF+50 |
| Purifier / unitless VOC | >=150 / <=100 | 1..500 | 5 | ON >= OFF+5 |
| Humidifier / %RH | <=40 / >=50 | 0..100 | 1 | OFF >= ON+5 |

Per-device thresholds remain independent; valid imported integers need not be step
multiples. A step clamps only its own value; invalid gap disables Save without
silently adjusting the other threshold. Preset change loads its default pair;
unsupported presets remain Manual-only. Values are demo policy, not health/
appliance-safety standards. No ppb-to-Sensirion conversion.

Factory/missing/invalid/legacy records yield Manual. Only a complete valid explicit
current Auto config opts in. Adopt fresh raw GPIOs before TX, including reconnect.
New Auto decisions require three consecutive eligible received frames AND the
existing 10-second hold after enable, committed limit change, confirmed transition,
boot/reconnect sync or sensor recovery. Keep wrap-safe ticks/revisions. Duplicates
and elapsed time alone do not trigger decisions. Invalid relevant sensors, loss,
pending commands or latched errors block new decisions; unrelated faults do not
pause healthy rules. Preserve each channel's pending intent.

Manual override uses the opposite of fresh readback and commits Manual; no timed
return. Switch positions always show reported GPIO XOR active_low, never pending
intent. Reconnect/late ACK/ordinary Save/limit edit cannot clear an error latch.
Only explicit Retry or a deliberate committed Manual->Auto transition re-arms;
Auto Retry adopts current fresh data and restarts hold rather than replaying an
obsolete target. No-op Save resets nothing. No forced physical-OFF guarantee on
link loss; real-load/MCU/radio/LCD/touch validation stays outside host acceptance.
