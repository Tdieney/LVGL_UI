# Smart Studio UI — design brief

Design specification implemented by the portable LVGL v8.4 module and verified by
the simulator regression suite. Requirements live in
[MIDTERM_ASSIGNMENT.md](MIDTERM_ASSIGNMENT.md); screenshots of every scenario
are in [screenshots/](screenshots/).

## Design system: zero-text high-contrast dark

Pure near-black `#050608` canvas with crisp `1 px` surface borders and semantic
accents. Tokens live in `ui_theme.h`; every style is `LV_STYLE_CONST_INIT` in
Flash (`ui_theme.c`).

| Token | RGB | Use |
|---|---|---|
| `canvas` / `dark` | `#050608` | Full-screen background; dark icon ink on solid Gold or Cyan fills |
| `surface` | `#101216` | Header corner buttons, `+`/`−` steppers, sensor icon tiles, idle circles |
| `pressed` | `#1A1E26` | Pressed state on dark surface buttons |
| `disabled` | `#0B0D10` | Disabled stepper button fill |
| `outline` | `#242830` | `1 px` border on dark surface buttons, tiles, and idle RX dot |
| `ray_off` | `#1C2028` | Unlit radial sun rays on Light |
| `ink` | `#F5F7FA` | Primary `76 px` hero numbers, `48 px` baud rate, active stepper icons |
| `muted` | `#58606E` | Off sun core/AC, unavailable `—` reading, disabled icons |
| `icon_idle` | `#A5ACB8` | Header corner icons and unselected scene icons |
| `gold` / `gold_half` | `#FFCE54` / `#8C702E` | Lit sun core/halo border, full and half-step sun rays, active scene fill (`#E6B842` pressed), pending pill border/icon on `#1F1A0C` |
| `cyan` / `cyan_soft` | `#48DBFB` / `#0E2C38` | Active AC snowflake and tile fill, humidity drop, apply pill (`#32C5E6` pressed), active-rate and RX dots |
| `coral` | `#FF7E67` | Valid room temperature thermometer icon |
| `error` / `error_soft` | `#FF6B6B` / `#261114` | Failed baud pill border/cross icon and background |

- **Typography (`ui_fonts.c`):** Plus Jakarta Sans SemiBold generated by
  `tools/generate_assets.py`. Visible text uses only `48 px` (`ui_font_48`,
  Connection baud rate and wide-reading fallback) and `76 px` hero digits
  (`ui_font_digits_76`: `0–9`, `-`, `—`, `°`, `%`).
- **Icons (`ui_icons.c`):** 31 `LV_IMG_CF_ALPHA_4BIT` masks recoloured at draw
  time (`img_recolor_opa = COVER`), generated from `assets/icons/studio/masters/`
  by `tools/draw_icons.py` and `tools/generate_assets.py`.
- **Widgets:** Base objects (`lv_obj`), labels (`lv_label`), and images
  (`lv_img`) only — no `lv_bar`, `lv_switch`, or `lv_dropdown`. Flat fills, no
  gradients, shadows, or idle animation.
- **Redundant cues (never colour alone):** Light pairs a solid Gold `44 x 44`
  sun core + `2 px` Gold halo border vs a hollow muted `2 px` outline core with
  the number of lit radial sun rays around 360°; AC pairs the `96 x 128`
  snowflake tile fill/border with setpoint digits; unavailable room sensors show
  `—`; Scenes invert fill and icon contrast; Connection changes the status pill
  icon (`✓` / `···` / `✕`) and shows a cyan dot on the active baud rate.

  `(14, 12)` (`scenes_24`) and `(422, 12)` (`sliders_24`). No header title bar.

  active-rate Cyan dot at `(236, 98)` when the displayed rate matches

Every interactive touch target is at least `44 x 44 px`.

## Touch

- A gesture locks to one axis after `10 px` and keeps it until release.
- A horizontal travel of `48 px` changes one page; the first and last pages
  clamp. It never dims, toggles or presses a button, even when it starts on one.
- On Light, tapping the sun medallion (`84 x 84`) toggles power; a vertical drag
  anywhere on the page dims relative to the start at `2 px` per percent (up is
  brighter). Dragging to `0` turns the light off; above `0` turns it on. A drag
  that starts on the sun medallion dims and does not toggle.
- Buttons, scene circles and baud controls act only on a tap. A swipe across the
  Scenes or Connection panel triggers nothing.
- During a drag at most one `LIGHT` event goes out per `100 ms`; the final value
  always goes out on release. A `LIGHT` from the PC during a held drag does not
  override the drag; after release the PC is authoritative again.
- Commands from the PC never produce an event back.
- An open panel owns every touch until it is closed and returns to the page it
  was opened from. Losing the touch (capture, focus, hiding a view) commits an
  established drag once and does nothing else.

## State

- **Light:** Power and brightness `0–100`. Off shows a hollow muted sun core
  (`#58606E` inside `#101216`) and 16 unlit radial rays (`#1C2028`); tapping the
  sun medallion on restores the last nonzero brightness (`80 %` initially).
  Brightness maps clockwise from 12 o'clock to `0–32` half-ray units (`0` at
  `0 %`, `clamp((level * 32 + 50) / 100, 1, 31)` across `1–99 %`, `32` at
  `100 %`): even units fill `units / 2` full Gold rays (`#FFCE54`), odd units
  add a half-step leading ray (`#8C702E`), hitting exact quarter turns at `25 %`
  (4 rays / 90°), `50 %` (8 rays / 180°), `75 %` (12 rays / 270°), and `100 %`
  (16 rays / 360°). A PC `power 1, bright 0` lights the Gold sun core and halo
  while leaving all 16 rays unlit (`effective_level = 0`).
- **AC:** Power and a `16–30 °C` setpoint (`25°` initially), kept while off
  (muted `96 x 128` snowflake tile and muted digits when off).
- **Scenes:** Home light `80 %` and AC `24 °C`; Sleep light off and AC `26 °C`;
  Away all off. A device change that no longer matches clears the selection.
- **Room:** Whole integers (`temp` in `°C`, `humid` in `0–100 %`, e.g. `27°` and
  `58%`, zero decimal points). Without a valid reading the value is `—` in muted
  `#58606E`.
- **Baud:** `9600`, `19200`, `38400`, `57600`, `115200` (initial), `230400`,
  `460800`, `921600`. Stepping `<` / `>` previews rates locally without sending
  an event; tapping the `✓` pill emits `STUDIO_CMD_BAUD` and locks the steppers
  and pill (`···`) until `ui_baud_complete()` reports the outcome. Failure keeps
  `applied_baud` and shows `✕` (tapping `✕` retries; stepping `<` / `>` or
  receiving a PC `BAUD` command resets to idle).

## Known notes

- The course Web starter sets Sleep to light on at 10 %; the assignment says
  off. After a SCENE the firmware publishes the resulting LIGHT and AC events
  (see [FIRMWARE_INTEGRATION.md](FIRMWARE_INTEGRATION.md)).

## Host figures, 2026-11-18

Windows simulator only — **not ESP32 hardware measurements**. `48` KiB LVGL heap
(`49,152` bytes), one `480 x 20` partial draw buffer (`19,200` bytes).

- Identical `LIGHT`/`AC`/`ENV` input x10 on every page: `0` flushes.
- Open Connection panel idle for `2,000 ms` after `ui_note_rx()`: `0` flushes.
- `100` page, scene, connection and stepper cycles: `28,056` bytes free before
  and after (`0` drift; settled minimum free `28,056` bytes; allocator-return
  minimum free `25,704` bytes; largest request `432` bytes; `0` failures).
- Temperature `27 → 28 °C`: `4` flushes, `37,296` pixels. Light
  `80 → 90 %`: `2` flushes, `4,320` pixels.
